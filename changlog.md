# Histórico de alterações — NppAIChat

Este arquivo registra as etapas e os materiais preparados para o projeto NppAIChat, um plugin que integra um chat de inteligência artificial ao Notepad++ por meio de APIs.

## Versão 1.0.0

### Projeto e distribuição
- Projeto NppAIChat criado para disponibilizar o chat de IA integrado ao Notepad++.
- Pacote ZIP com os arquivos do plugin (incluindo as DLLs necessárias) adicionado ao repositório para instalação manual: [`NppAIChat_v1.0.0.zip`](NppAIChat_v1.0.0.zip).
- Material de distribuição e implantação publicado no repositório.

### Documentação e uso
- Documentação principal do projeto incluída no [`README.md`](README.md), com visão geral, requisitos, instalação manual e solução de problemas.
- Manual detalhado adicionado em [`docs/Handbook.md`](docs/Handbook.md), com orientações de uso e configuração dos serviços de IA/API compatíveis.
- Material de apresentação preparado em [`docs/forum_post.md`](docs/forum_post.md).
- Imagem de demonstração incluída em [`image.png`](image.png).

### Arquivos de apoio
- Instalador do Notepad++ 8.9.9 para Windows 64 bits disponibilizado como referência: [`npp.8.9.9.Installer.x64.exe`](npp.8.9.9.Installer.x64.exe). O Notepad++ não precisa ser reinstalado se já estiver instalado.

## Observações
- A instalação do plugin é manual: extraia o ZIP e copie a pasta do plugin para a pasta `plugins` da instalação do Notepad++.
- O uso de serviços de IA requer conexão com a internet e, conforme o provedor, uma credencial de API válida. Mantenha as chaves privadas.
- Consulte o README e o manual para instruções completas e detalhes de configuração.
